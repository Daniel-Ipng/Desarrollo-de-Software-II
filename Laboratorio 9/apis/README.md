# Publicaciones

Aplicación Flutter para consultar, crear, editar y eliminar publicaciones mediante la API de ejemplo [JSONPlaceholder](https://jsonplaceholder.typicode.com/).

## Funcionalidades

- Consulta y recarga de publicaciones.
- Vista de detalle con comentarios.
- Creación y edición de publicaciones.
- Eliminación de publicaciones con confirmación.
- Manejo de errores de conexión y tiempos de espera.

Los textos de ejemplo que devuelve JSONPlaceholder se muestran tal como los proporciona el servicio; la aplicación no los traduce automáticamente.

## Requisitos

- Flutter instalado y configurado.
- Un emulador o dispositivo conectado.
- Conexión a Internet para consultar la API.

## Ejecución

```bash
flutter pub get
flutter run
```

## Pruebas

```bash
flutter test
```
